## 💬 HOW TO USE KIRO EFFECTIVELY

### **DO ✅**
- Copy **exact prompts** từ TASK_BREAKDOWN.md
- Ask one task at a time
- Reference files: "In app/products/page.tsx, add..."
- Request TypeScript everywhere
- Ask for "Server Component" vs "Client Component" explicitly

### **Example conversation with Kiro**:
```
You: [Copy prompt từ Task 6: Homepage]

Kiro: [Generates code]

You: Great! Now add loading skeleton while fetching products

Kiro: [Updates code]

You: Perfect. Save this to app/page.tsx

Kiro: [Confirms]
```

### **DON'T ❌**
- Ask vague questions ("make me a product page")
- Mix multiple tasks in one prompt
- Forget to test after each task
- Skip TypeScript
- Ignore the rendering strategy table

## 🐛 TROUBLESHOOTING

### "Prisma types not found"
```
→ Run: npx prisma generate
→ Restart TypeScript server in editor
```

### "API route not working"
```
→ Check: Is it revalidating cache correctly?
→ Check: Is Zod validation correct?
→ Test: curl http://localhost:3000/api/products
```

### "Build fails - missing dependencies"
```
→ Run: npm install [package]
→ Check: All imports are correct paths
→ Check: No circular imports
```

### "Component not rendering data"
```
→ Is it a Server Component that should fetch?
→ Or Client Component that needs useEffect?
→ Check props are typed correctly
→ Check data is passed from parent
```

## 🎁 BONUS: WHEN YOU GET STUCK

If Kiro can't generate good code:

1. **Be more specific**:
   - ❌ "Make a product component"
   - ✅ "Create ProductCard component that displays product image, name, price, and an Add to Cart button. Use TypeScript for props."

2. **Provide context**:
   - Reference existing files
   - Share the Prisma schema
   - Show the TypeScript interface

3. **Break it down**:
   - Instead of "build checkout flow"
   - Ask: "create checkout page with SSR that fetches current prices"
   - Then: "create server action to create order"

4. **Ask for validation**:
   - "Double check this uses TypeScript typing"
   - "Verify this Prisma query is optimized"
   - "Check if this properly revalidates cache"
